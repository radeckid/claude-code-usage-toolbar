## What's Changed

### ✨ New
- **Per-model weekly limit** — the weekly bar now shows the model-scoped limit reported by the API (e.g. *Current week (Fable)*), with the model name read dynamically. This replaces the old Sonnet/Opus windows that the API no longer returns.
- **Extra usage from `spend`** — the cost bar is now driven by the API's richer `spend` object (accurate currency and percentage, respects severity).
- **Menu bar icon style** — new option in **Settings ▸ Display ▸ Menu bar icon** to switch between the **Ring** and a **Bars** mini chart (session · week · model).

### 🛡️ Hardening
- Guarded percentage `Double → Int` conversion against NaN/∞/overflow from the API (removes a potential crash).
- Safe fallback for the cache directory instead of a force-unwrap.

**Full changelog:** https://github.com/radeckid/claude-code-usage-toolbar/compare/v1.0.9...v1.1.0
