## What's Changed

### ✨ New
- **Reset time when the limit is hit** — when the 5-hour session limit reaches 100%, the menu bar now shows an hourglass with the time the limit resets (e.g. *⧗ 3:30pm*, or the date if it resets on another day) instead of the 😢 emoji. Works the same in both the **Ring** and **Bars** icon styles.

### 🔧 Improvements
- Reset times shown in the menu bar are now localized (English/Polish) with the same formatter used by the dropdown panel.

**Full changelog:** https://github.com/radeckid/claude-code-usage-toolbar/compare/v1.1.0...v1.1.1
